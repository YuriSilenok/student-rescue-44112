# Студпомощь 44·112

Расписание студентов КГУ и поиск времени, когда можно подойти к преподавателю для сдачи долгов.

Сайт: **https://силенок.рф:44112**. 44 — Костромская область, 112 — помощь студентам.

## Возможности

- Выбор учебного года, группы и подгруппы.
- Расписание по дням с навигацией по неделям и выбором даты.
- Список преподавателей, заметки о долгах, отметка «сдано».
- Подходящие интервалы до, между и после пар без автоматического запаса на дорогу.
- Раскрываемый блок каждой пары студента с занятиями выбранных преподавателей в это время, предметами, группами и аудиториями.
- Общая сетка пар группы и выбранных преподавателей: видны ранние и поздние пары преподавателей и их занятия в дни без пар у студента. Преподаватели без занятия в соответствующем интервале не выводятся в карточку.
- Окна преподавателей (перерывы от часа между занятиями) и общие свободные интервалы со студентом. Аудитории до и после окна служат ориентиром; местонахождение в самом окне неизвестно.
- Отдельный список возможностей и занятий, совпадающих с парами студента.
- Аудитории, исходные расписания и дата обновления КГУ.
- Автоматическое обновление данных каждые 5 минут и при возвращении в окно.
- Профиль хранится в localStorage; регистрация и пароль ЭИОС не нужны.
- PWA: манифест, установка средствами браузера, сохранение оболочки для открытия без сети. Актуальные расписания требуют подключения.

У преподавателя в показанное время **идёт занятие**. Приложение не гарантирует присутствие и не записывает на консультацию. Сдачу нужно согласовать.

## Разработка

Требуется Python 3.12+ и Node.js 24+. В корне проекта:

```sh
python -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 44113
```

В другом терминале:

```sh
cd frontend
npm install -g pnpm@11
pnpm install --frozen-lockfile
pnpm dev
```

Windows: используйте `.venv\Scripts\python.exe`. Vite передаёт `/api` на локальный FastAPI.

## Развёртывание

Push в `main` автоматически запускает `.github/workflows/deploy.yml`: зависимости → сборка React → архив → отправка на VDS по SSH. Тестов в workflow нет по решению владельца проекта.

GitHub Secrets: `VDS_HOST`, `VDS_SSH_KEY`, `VDS_KNOWN_HOSTS`. Ключ имеет только forced-command доступ к приёму релиза; пароль root в GitHub не передаётся. Аккаунт `student-deploy` может перезапускать только `student-rescue.service`. Приложение работает от отдельного пользователя `student-rescue`.

Каталог `/opt/student-rescue`, релизы в `releases/`, символьная ссылка `current` переключается после сборки зависимостей. При невозможности запуска службы возвращается предыдущий релиз. Служба слушает `127.0.0.1:44113`, nginx принимает HTTPS на `44112`. Используется существующий сертификат домена. Конфигурации: `deploy/`. Изменения service/nginx/receive устанавливаются администратором отдельно: автоматическая поставка обновляет приложение, а не системные права.

```sh
systemctl status student-rescue
journalctl -u student-rescue -n 80 --no-pager
cat /opt/student-rescue/current/REVISION
```

Ручной откат: переключить `current` на нужную папку в `releases/` и выполнить `systemctl restart student-rescue`. Старые релизы сохраняются для отката, администратору следует удалять ненужные по мере роста диска.

## Источник данных

Публичный JSON API `https://eios.kosgos.ru`. Сервер использует только GET запросы к фиксированным маршрутам, кэширует справочники на час, расписания на 5 минут. Если источник недоступен, копия возрастом до суток показывается с предупреждением. Кэш находится в памяти процесса и очищается при перезапуске.

Параметр учебного года — `2026-2027`, а не `2026`. В проверенных данных `номерПодгруппы=0` даже для подгрупп: основная пометка извлекается из текста `дисциплина` (`п/г 1`, `п/г 2`). Общие пары показываются всем. Неопознанная пометка подгруппы отображается с предупреждением. Циклические расписания пока не поддержаны, сервер сообщает об этом вместо неверного расчёта окон.

Окна считаются пересечением интервалов занятий преподавателя со временем без пар студента; границы собственных пар не расширяются. Время на дорогу студент оценивает самостоятельно. Минимальный подходящий интервал — 10 минут. Это оценка по расписанию, без карты корпусов и фактической геолокации.
